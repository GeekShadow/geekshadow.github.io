31 mars 2014

Sortie de Windows XP SP4

Général Logiciels
Microsoft décide de faire marche arrière et viens d'annoncer aujourd'hui un 4ème Service Pack pour Windows XP. Le support devait s'arrêter le 8 avril 2014, mais à la demande de beaucoup (administrations, banques et écoles) Microsoft a préparé un ultime Service Pack pour étendre ce support jusqu'à début 2016. Que contient ce Service Pack ? La bonne nouvelle, c'est qu'il intègre Internet Explorer 11, la dernière version du navigateur phare. Mais ce Service Pack propose aussi tous les correctifs qui sont sortis depuis le SP3. Un autre ajout intéressant est le mode Ready8 © qui permet de savoir si vous êtes prêt à migrer sur Windows 8.1. En effet ce mode permet d'activer l'interface Metro Modern UI et d'essayer la navigation avec les « tuiles ». Ce Service Pack 4 (Build 5.1.2600.1337) est bien entendu cumulatif (il intègre les mises à jour du SP3). Attention : une clé valide est nécessaire pour installer le SP4 ! Si vous êtes en possession d'une copie frauduleuse, un mail d'avertissement vous sera envoyé et votre PC pourra être bloqué. (Votre IP pourrait être communiquée à la NSA) Pour télécharger le Service Pack 4, rendez-vous sur le site de Microsoft ! (Environ 883 Mo) Et n'oubliez pas de posséder un anti-virus à jour comme par exemple Norton ou McAfee. Que pensez-vous de cette stratégie à deux vitesses opérée par Microsoft ?

Source : Microsoft
