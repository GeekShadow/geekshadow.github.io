Nouvelles sorties Mozilla

Actualité Général Logiciel Libre Logiciels Open Source Web

Mozilla viens de publier les nouvelles moutures de Firefox (navigateur web) et Thunderbird (client de messagerie), toutes les deux estampillées de la version 5. Dorénavant les versions des produits de Mozilla correspondront (les logiciels étant basé sur le même moteur).
  • Téléchargement de Firefox 5 ici : http://europe.mozilla.org/fr
  • Téléchargement de Thunderbird 5 ici : http://www.mozilla.org/fr/thunderbird/
Parmi les changements, Firefox 5 prends désormais en charges les animations CSS, une option "ne pas me pister" est disponible dans la section "Vie Privée" et toujours diverses améliorations des performances. Thunderbird 5 est plus rapide, possède le nouveau gestionnaire d'extensions (introduit dans Firefox 4), intègre un nouvel assistant de création de compte, permet de réorganiser facilement les onglets, affiche la taille des pièces jointes, prend en charge les plugins dans les flux RSS (par exemple vidéo). Mozilla c'est aussi le moteur XULRunner qui permet de créer des applications tierces comme Instantbird, un logiciel de messagerie instantanée multi-protocoles qui viens de sortir en version 1.0 ! Pour en savoir plus et le télécharger, rendez-vous sur le site : http://www.instantbird.com
